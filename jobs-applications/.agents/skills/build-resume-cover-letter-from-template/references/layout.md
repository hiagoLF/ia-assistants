## Origem das fontes e ícones

As fontes Calibri em `assets/fonts/` foram extraídas dos PDFs fornecidos pelo próprio usuário para seu uso pessoal; são subconjuntos com os glifos existentes nos anexos. Não representam uma licença geral para redistribuição pública. A Roboto Regular veio da instalação local do Android Studio. Arial é fallback local para caracteres ausentes.

Os quatro pequenos ícones de contato da carta foram preservados a partir da renderização do PDF original; não dependem da aparência de emoji do sistema. Nos PDFs adaptados, os contatos ao lado dos ícones continuam sendo texto selecionável e links clicáveis.

## Ajuste para caber

A escala do corpo segue 100%, 97,5%, 95%, 92,5% e 90,476% (9,5pt para o corpo de 10,5pt). Primeiro tente esses tamanhos. Se ainda ultrapassar o limite, reduza o texto. Nunca use corte, ocultação, transformação gráfica de toda a página ou remoção de fatos essenciais para simular conformidade.
